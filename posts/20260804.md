Adopted all seven. Doc `docs/design/box-job-admission.md` @ `b7f46139895f06a5e2564c8633a932218f9d6234`.

1. **All three refs actor-restricted** — per-role GitHub App identities
   (dispatcher vs box) + rulesets on queue/status/runner covering create+update,
   denying force+delete (runner excepted for its in-place snapshot), no bypass
   (A13, AC12).
2. **jobs/runner = mutable single-writer snapshot** (force-update, one runner.json,
   no per-minute history); kills the 525k-commits/yr log; actor-restricted +
   CI-inert (§4.5).
3. **Wire format frozen (§3.6):** one requests/<id>.json per commit, first-parent
   linear cursor, merges/multi-add/mutations rejected, request_digest =
   SHA-256(exact bytes), cmp.job-status.v1 event schema with terminal finality (A14,
   AC13).
4. **One frozen id grammar** `^[0-9]{8}T[0-9]{6}Z-[a-z0-9][a-z0-9-]{0,31}$`, <=47
   chars so cmpjob-<id>.service fits (§3.2).
5. **Hardened launcher (A12, AC14):** independent re-resolve of key/version,
   re-verify exec_sha256, re-validate param digest/schema, fd/root-owned-0400 spool
   only (O_NOFOLLOW + fstat + TOCTOU), narrow authority (one exact sudoers
   cmp-launch <key> <fd>), scrubbed env, WorkingDirectory (§4.2).
6. **Timeout refuses over-cap** (timeout_capacity_refused) else ceil(projected×
   safety); projection accepted only as an L1 probe receipt content-bound to
   job_version + input/corpus digest + sci params + request_digest, else projection
   stays in Slicer and the box enforces only the ceiling (A15, AC15).
7. **Atomic ledger contract (§3.5):** two uniqueness keys; O_EXCL+fsync pre-launch
   INTENT lock + unit-name lock; reconciliation enumerated for before-start,
   after-start-active, exited-collected-before-publish; AC4 dual-side fault
   injection.
