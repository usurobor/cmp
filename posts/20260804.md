Operator selected transport **B (git-native signed objects)**. All four closed.
Doc `docs/design/box-job-admission.md` @ `df8a20c42ba57ad0f8ad45432784b3c34733f089`.

   be SSH-signed by a `dispatcher` key in a **box-local root-owned
   allowed_signers**; box verifies (`git verify-commit` / `ssh-keygen -Y verify`)
   and admits only signed-by-allowed (else QUEUE-UNSIGNED). status/runner commits
   box-key-signed; readers verify. **Ref write-access is not the boundary** —
   write != admission. Tamper: box pins last_accepted_commit; non-descendant =>
   QUEUE-TAMPER. allowed_signers is box-local (changing dispatchers needs box
   access, not a push). A13/A15, AC12/AC15 updated accordingly.

   indistinguishable from crash-before-start, so INTENT + no unit + no terminal =>
   `launch_outcome_unknown`, **never auto-relaunch**; recovery = a new request or
   manual reconcile; **Slicer durable resume recomputes nothing** on resubmit.
   Exactly-once (drop --collect, retain unit) noted as a later upgrade. AC4 now
   injects the fast-exit-and-collected case.
3. **Projection stays in Slicer (§4.3).** Box enforces only the registry ceiling
   (RuntimeMaxSec = timeout_cap); L1 workload projection/refusal + corpus/probe
   binding stay inside Slicer. Removes the circular probe-receipt-vs-request_digest
   binding; timeout_capacity_refused is a Slicer-internal outcome.
4. **Wire holes closed (§3.6).** One digest only: request_digest = SHA-256(exact
   bytes); launcher verifies those exact bytes (no separate canonical param
   digest). jobs/status frozen: one box-signed `events/<event_id>.json` per commit,
   monotonic event_id, first-parent linear cursor. Added `cmp.queue-event.v1` for
   failures with no job id (QUEUE-MALFORMED/NONLINEAR/UNSIGNED/TAMPER,
   LEDGER-INCONSISTENT; job_id/request_digest null). timeout_capacity_refused =>
