## Sigma-general lessons (raw for home r1) — over-engineering via local optimization

Context: at cmp I drove a box-runner design through 5 versions + 4 code rounds
with a rigorous reviewer (Pi). Each review correct, each patch compliant, yet the
artifact grew 150 -> 1023 lines for a 1-dispatcher/1-job/~1-per-hour/private-repo
box. Operator called KISS/YAGNI. Full RCA:
threads/rca/2026-08-04-runner-overengineering.md @ cmp 975a590. Durable lessons
that generalize beyond cmp:

- **L1 — Optimize the arc, not the step.** Local correctness (reviewer) x local
  compliance (me) = unbounded scope. Someone must hold GLOBAL cost/benefit; as the
  implementer, that is partly my job, not only the operator's.
- **L2 — State + bound the threat model (and non-goals) BEFORE hardening.** The
  spiral was driven by adversaries introduced ad hoc each round. A "defect"
  against an out-of-scope adversary is not a defect. Write who we defend against
  and what is explicitly out of scope, first.
- **L3 — Match mechanism to cardinality.** Single-writer / single-tenant /
  low-rate / private != Byzantine / multi-tenant. Signed objects, anti-rollback,
  privileged verb boundaries, transactional outboxes are for adversarial
  multi-party systems. Default YAGNI; add adversary hardening only when a real
  adversary exists.
- **L4 — Deference to an individually-correct reviewer can suppress the necessary
  question: should we build this at all / this much?** Challenge the FRAME, not
  just the comments. I should have raised KISS/YAGNI myself ~mid-spiral, not
  waited for the operator.
- **L5 — A tripped explicit cost guard is a STOP-and-simplify signal, not
  advisory.** The line-budget was blown 632->868->1023 and flagged each time;
  flagging while pushing through is not honoring the guard. Trip = whole-design
  re-review.
- **L6 — Reuse the guarantee at the adjacent layer; don't re-solve it.** Slicer
  already had durable resume; the runner over-invested in exactly-once /
  crash-consistency it already covered.
- **Meta — tooling != judgment.** The git-ref dialogue (cnos#698) + cell-dispatch
  loop worked well (many honest round-trips, incl. self-correcting a 17/17
  overclaim to PARTIAL). The failure was scope judgment. Keep the machinery; fix
  the judgment.

cnos), not cmp-specific. Compact accordingly.
