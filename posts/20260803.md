Governing semantic contract


Contracts state local settlement laws. CMP reconstructs a warranted global joint-settlement law before considering prices.


For a binary component C, each contract i induces a settlement payoff f_i: Ω → {0,1}. Histories producing the same settlement vector are equivalent, yielding an admissible joint-state set S_C ⊆ {0,1}^{|C|}. Equivalence, implication, exclusion, exhaustiveness, and partition relations constrain S_C. A coherent shadow-price vector lies in P_C = conv(S_C).


The semantic atlas is frozen without price, volume, resolved outcome, resolver status, or comments. Only then does CMP test whether the executable quote region Q_t intersects P_C. Q_t ∩ P_C = ∅ is a price-incoherence candidate under the fixed atlas; it is not automatically a trade.


STRICT_ARBITRAGE_WITNESS requires an executable portfolio with positive worst-case net payoff across every admissible settlement state and every retained semantic interpretation after fees, spread, slippage, depth, capital lock, and void/resolution risk.

Slicer boundary and retrieval-instrument design


Slicer is not the coherence engine and not the trader. Its bounded role is:


filter → embed → retrieve → emit blinded fixtures


It performs observation/filtering and heuristic relation-candidate search. It emits candidate pairs only—never identified relations, a global settlement law, price incoherence, or trade witnesses.


Converged constraints:
• preserve title/headline separately from normative resolution rules;
• exclude price, volume, resolved outcome, resolver status, and comments from retrieval/classification inputs;
• freeze corpus, filter, embedding, ANN configuration, controls, and gate policy before held-out evaluation;
• measure computational recall and relation-control recall before subtracting the frozen mechanical baseline;
• define novelty by exact set subtraction from the actual baseline;
• separate calibration controls from held-out controls and retain failed attempts;
• report novel candidate yield as a result, not an instrument-validity gate;
• use stage-specific memory bounds, capacity refusal, checkpointing, surfaced errors, and measurable failure cost;
• prove the generic spine on a synthetic stage before model/corpus/ANN work;
• require stage-specific oracles for embed, index-build, retrieve, and emit.
