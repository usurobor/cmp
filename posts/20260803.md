## 2026-08-03 — TSC north-star correction: generation is the center, warrant is the discipline

Captured verbatim-in-substance at Axiom's instruction ("most importantly capture
this"). This concerns `usurobor/tsc`, not cmp; recorded here because tsc push
access is not currently granted. **For home: promote to an authoritative
`docs/design` record in `usurobor/tsc` when access is available.** This
supersedes the practical-engineering framing that over-centered repository
quality.

### The correction

I over-centered the practical engineering wedge. Repository quality is a valuable
application and self-hosting test, but it is not the reason TSC exists.

The center is: **TSC is a generative reasoning system for recovering a
higher-order generator from partial or opposed articulations — and for
determining what, if anything, warrants that recovery.** The repository work
proved that methodology-as-code is operationally useful. It did not yet exercise
the generative heart of TSC.

### The actual TSC stack

    C≡                   expresses articulation
    Articulation Ascent  discovers a higher-order generator
    CM                   programs the discovery and test procedure
    TSC Core             warrants, underdetermines, refutes, or refuses
    coh                  compiles and executes
    CM0                  assesses the methodology as an instrument
    domain               supplies observations, interventions, and oracles

Repository Coherence is ONE domain application:
Repository → Legibility / Structure / Operability articulations → composable CMs
→ evidence-bound defect receipts.

### The fundamental program

    one point of view a
    → derive a genuine polar view b
    → identify the obstruction that makes a and b appear incompatible
    → recover candidate higher-order generators W
    → preserve the candidate fiber when several W remain
    → descend W into existing and novel articulations
    → test whether those articulations return to the same W
    → warrant, underdetermine, refute, or refuse

Conceptually:  a ≡ b  ⟹  { W_i | W_i lawfully articulates as a and b }.

Decisive test is generative:  W_i --[unattempted query q]--> c
and where appropriate round-trip:  Ascend(Descend(W_i, q)) ≃ W_i.
A candidate that merely summarizes the inputs is not the sought generator. It
must generate articulations it was not simply fitted to repeat.

### What v4.1 contributes

The move from scoring to receipts was not the destination — it is the discipline
needed to make the generative operation trustworthy. Without v4 machinery an LLM
can always produce an impressive-sounding "higher synthesis" (duality ≡ toaster →
four persuasive paragraphs): the profundity-generator failure.

v4.1 mathematics provides the resistance: declared candidate class; joint
generator + atlas realization; search-strength claims; equivalence indexed by
observations/interventions; fit and complexity; candidate fibers; held-out
descent; failed and unresolved alternatives; identification only within a
declared model. Core explicitly treats a polar source as a claim to be realized,
retains generator+atlas together, and distinguishes: no realization,
over-budget realization, underdetermination, identification, failed tests,
unresolved tests.

So:  **Generation is the purpose. Warrant is the discipline. Empirical
measurement is one possible way of earning warrant** — not constitutive in every
domain. A warrant may instead be: formal proof · typecheck · construction ·
counterexample · held-out prediction · intervention · historical-text recovery ·
refusal.

Hence "repo quality is a side effect" is directionally right, but better called
the **first substantial application and self-hosting calibration domain**, not an
accidental side effect.

### The risk we nearly repeated

Pre-v4, TSC led with generative ≡ language but compressed the structure into
scalar evaluators. With v4 we repaired warrant, but so much Repository-Coherence
focus risked making TSC look like: agent-evaluation framework + policy-as-code +
repo-quality tooling — useful, but losing the original program one layer up.

CUE language work has proven: leaf CMs, composite CMs, generic receipts,
deterministic result derivation. But its README still defers typed external
execution bindings and embedded C≡ articulation. I.e. **we have encoded the
warranting architecture; we have not yet encoded the generative operation that
architecture exists to warrant.**

### The CM language must be generative, not merely evaluative

The F#-style computation-expression language must support checks, but its standard
library must also contain articulation primitives — not only `Git.tracked`,
`Markdown.checkLinks`, `Schema.validate`, `Cm.run`, `decide`, but:
`Articulation.compileView`, `.unclose`, `.polarize`, `.nameObstruction`, `.lift`,
`.retainFiber`, `.descend`, `.roundTrip`, `.testGenerativity`.

Flagship generative CM:

    cm articulationAscent v0.1
      (view: PointOfView, question: Question)
      -> AscentReceipt
    {
      let! frame       = Articulation.compileView view
      let! polarities  = Articulation.polarize frame
      let! obstruction = Articulation.nameObstruction frame polarities
      let! candidates  = Articulation.lift frame polarities obstruction
      let! descents    = candidates |> Articulation.descendHeldOut question
      let! roundTrips  = Articulation.roundTrip descents
      retain frame polarities obstruction candidates descents roundTrips
      decide
      | InvalidPolarity        when polarities.empty
      | NoTensionIdentified    when obstruction.absent
      | DecorativeLift         when candidates.nonempty and obstruction.survives
      | AscentUnderdetermined  when candidates.inequivalent.count > 1
      | LiftValidated          when obstruction.killed
                                and heldOutGenerativity
                                and roundTripSupported
      | Unresolved
      forbid fabricateEvidence eraseAlternatives equateFluencyWithWarrant
    }

Repository Structure demonstrates CMs can CHECK. Articulation Ascent must
demonstrate CMs can GENERATE and DISCOVER.

### Roadmap hierarchy correction

CM0 stays the right immediate language test (forces generic leaf methodologies,
typed provider operations, instrument subjects/assessments, authority
boundaries, self-application without self-authorization) — but CM0 is the
instrument-calibration layer, NOT the flagship. Decisive sequence:

1. Repository Coherence — proves composition.
2. Structure + Legibility — prove distinct leaf methodologies.
3. CM0 — proves reflectivity and instrument assessment.
4. Articulation Ascent — proves generative methodology.
5. Articulation Ascent self/round-trip fixtures — prove the language can
   generate, preserve alternatives, test held-out descent, and refuse decoration.

**Articulation Ascent = the fifth example and first flagship CM.** Public
positioning should wait until it exists, or the audience will reasonably conclude
TSC is an elaborate quality-assessment framework.

### The true public identity

TSC is a language and runtime for generative reasoning with proof-carrying
receipts. It helps an agent move from one point of view to its polarity, recover
candidate higher-order generators that make both lawful, generate new
articulations from those candidates, and state exactly what the evidence
warrants.

Compact:  "From opposed views to a generative whole — with receipts."
Or:  "Articulate. Lift. Generate. Warrant."

Repository Coherence is then the concrete engineering story (encode what a
coherent repository means, measure an exact commit, prevent unsafe repairs,
verify closure) — evidence of generality, not the final identity.

### The invariant to freeze

    C≡   expresses.
    Ascent generates.
    CM   programs.
    TSC  warrants.
    coh  executes.
    CM0  calibrates.

Governing sentence for remaining language work: **A CM language that can only
assess existing artifacts has not yet recovered TSC's generative purpose.** The
repo-quality work gave a strong warranting substrate; the next major test is to
put the generative operator back at the center and prove the language can perform
the operation TSC was invented to teach an LLM.
