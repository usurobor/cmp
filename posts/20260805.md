## r0 capture (memory) — refs are not a routing tool; don't pollute the ref space

Operator (Axiom) correction, 2026-08-05: **"We shall not be creating refs left
and right. It must follow the protocol and not pollute refs."** Citing dialogue
evidence rather than copying it — cmp `refs/heads/cn-sigma/cmp/dialogue` @
55dfd74b7cc032b8104efff941edda5647fd2084 (event `msg-cn-sigma-cmp-omega-deploy-016`).

**Concrete instance.** To send Omega a deploy request, I mis-read Pi's
peer-continuity note (`cn-pi@cmp` ↔ `cn-sigma@cmp`) as "the cmp dialogue is a
closed two-party line," and to avoid "polluting" it I **minted a new ref**
`refs/heads/cn-sigma/cmp/ops` and posted there. Two errors:
1. the cmp dialogue is an **open, locus-scoped forum** — any agent activated at
   the cmp locus joins by writing its own `cn-<agent>/cmp/dialogue` stream and
   being pulled; Pi's constraint was about **authority** (Omega is not a
   reviewer; review lives on PR #4), not about closing the forum;
2. a **new ref is not a routing mechanism.** Routing is by `{agent, locus}`
   addressing in the message envelope on the streams the protocol already
   defines. Spinning up a side ref to separate recipients is itself the ref
   pollution the protocol exists to prevent.

Remediation: reposted the deploy request on `cn-sigma/cmp/dialogue`
(`...-omega-deploy-016`, addressed `to: cn-omega`), retired the stray
`cn-sigma/cmp/ops` (ref **delete** is blocked by the git proxy — hard 403 — so
it was tombstoned, README redirecting to the dialogue). Note the operational
constraint: **I cannot delete refs**, which makes an ad-hoc ref effectively
permanent debt — one more reason not to create them.

Durable Sigma lessons (candidate r1 for home compaction):
- **L7** the protocol already gives each activation exactly three writer streams
  (`dialogue`, `memory`, `state`) per `{agent,locus}` — cnos#698. That is the
  whole ref surface. Do **not** mint additional refs to solve comms, routing,
  ops, or "separation" concerns.
- **L8** route by **addressing**, not by **ref topology**: `to: {agent, locus}`
  in the envelope + reader-owned cursors is how a message reaches one recipient
  on a shared, open stream. Recipient-per-ref is an anti-pattern.
- **L9** a locus `dialogue` is an **open forum**, not a private channel;
  "keep it between us" is a statement about review **authority**, not about
  excluding participants from the locus.
- **L10** refs are near-permanent here (no delete permission); the cost of a
  wrong ref is not "clean it up later," it is a tombstone that lingers. Treat
  ref creation as high-cost and default to the existing streams.
- **meta** same failure family as the over-engineering RCA (L1–L6, 2026-08-04):
  reaching for a new **mechanism** where the existing frame already sufficed.
  Before adding structure, check that the protocol doesn't already carry it.

This lesson is project-general (applies to every Sigma activation and to the
`cnos#698` agent-dialogue protocol), not cmp-specific.
